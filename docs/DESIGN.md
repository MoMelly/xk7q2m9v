# 界面设计规范

基准机：iPhone 15 Pro Max / 当前最新系统（iOS 26）。§4 的数值是起始值，真机截图到位后按截图校准。

这份文档只管**看起来是什么样、点起来是什么反应**；代码分层、复用、数据、构建规则在 `docs/STANDARDS.md`，不在这里重复。

---

## 1. 这份规范要解决的

2026-11-05 的 8 张截图里，日历、健康、音乐、设置四页是同一个结构：自造页头（图标 + 22pt 标题 + 说明），下面一排独立白卡，每张卡带白描边和阴影。换掉标题和文字就能当任何页面用。日历页是 6 张卡列 5 条日程，没有月份、没有日期格、没有事件色点、没有时间轴、没有底部工具栏。

代码上的原因：`ScenePage` 用一个 `row(title:subtitle:detail:symbol:)` 分发全部 8 个页面，`WhiteCard` 给每一行都铺白底 + 描边 + `radius 8 / y 3` 阴影。这套容器本身没错，错在**所有 App 都用它**，以及浅色分组列表不该有阴影。

页面之间看着割裂，不是因为它们各不相同，是因为它们共享一个不属于任何系统 App 的自造结构。

## 2. 基准设备与画布

| 项 | 值 |
|---|---|
| 基准机 | iPhone 15 Pro Max，iOS 26；`glassEffect` 可用，锁屏字形玻璃不需要低版本降级分支 |
| 逻辑画布 | 430 × 932 pt，@3x |
| 顶部 | Dynamic Island / 状态栏区按系统高度留白，自绘状态栏不压内容 |
| 底部 | Home Indicator 区 34 pt |
| 页面左右边距 | 16 pt（系统设置的实际值，之前写的 20 偏宽） |
| 单位 | 一律 pt，不用屏幕比例、不用百分比 |

锁屏、桌面、状态栏、Home Indicator 都是自绘的，尺寸对齐这台机器；App 内页在这个画布里按系统 App 的度量排。

## 3. 三条硬规则

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **一个 App 一种结构** | 日历要有日历的网格和时间轴，备忘录要有文件夹列表和搜索框，相册是照片网格。共用一个列表容器就永远是同一个页面 |
| 2 | **页面里不出现裸视觉值** | 颜色走 `Theme.*`、圆角走 `Metrics.*`、阴影走 `Theme.Shadow`、分组走组件。现在 `WhiteCard` 里写死 `Color.white.opacity(0.9)` 和 `Theme.ink.opacity(0.07)`，改一处要全局搜 |
| 3 | **深浅按 App 分，不由外壳一刀切** | `MiniPhoneApp` 的 `.preferredColorScheme(.dark)` 会翻掉所有语义色，设置页发黑、健康页开关文字变白底白字都来自这里。改成每个页面显式声明 `AppSurface` |

## 4. 视觉 Token

### 4.1 间距

| token | 值 | 用在哪 |
|---|---|---|
| `xxs` | 4 | 图标与文字、标题与副标题 |
| `xs` | 8 | 行内元素 |
| `s` | 12 | 区块内部 |
| `m` | 16 | 行内边距 |
| `l` | 20 | 页面左右边距 |
| `xl` | 24 | 区块分隔 |
| `section` | 35 | iOS grouped 分组之间 |
| `row` | 44 | 单行列表行高；带副标题 58 |

### 4.2 圆角

| token | 值 | 用在哪 |
|---|---|---|
| `grouped` | 10 | 分组列表（`.continuous`） |
| `card` | 12 | 浮层卡片、小组件 |
| `icon` | 22% 边长 | 系统 squircle 近似 |
| `pill` | 高度 / 2 | 按钮、标签 |
| `glass` | 28 | 玻璃容器 |

现在全项目统一用 16，日历页看起来像网页卡片，这是原因之一。

### 4.3 字阶

SF Pro。现有 `Theme.serif` 不用于系统 App 的界面标题，只留给信件体一类玩法文案。

| 用途 | 字号 / 字重 |
|---|---|
| 页面大标题 | 34 / bold |
| 导航标题 | 17 / semibold |
| 正文、列表标题 | 17 / regular |
| 副文、说明 | 15 / regular |
| 脚注 | 13 / regular |
| Caption、时间戳 | 12 / regular |

### 4.4 颜色

两套语义色，页面按 `AppSurface` 取，不用 `.primary` / `.secondary` 这类会跟着配色方案翻转的值。

| role | 浅色 App | 深色 App |
|---|---|---|
| 背景 | `#F2F2F7`（systemGroupedBackground） | 壁纸 + 玻璃 |
| 行 / 卡片 | `#FFFFFF` | 半透明玻璃 |
| 主文字 | `#000000` | 白 |
| 次文字 | `#3C3C43` @ 60% | 白 @ 70% |
| 分隔线 | `#C6C6C8` @ 60% | 白 @ 15% |
| tint | `#007AFF` | 现有 `Theme.mint` |
| 分组标题 | 灰 13pt | 同左 |

浅色 App：日历、设置、备忘录、通话记录、健康、音乐、西瓜皮（含市集）。
深色 App：信息、动态，沿用现有玻璃体系。

西瓜皮和市集都用品牌红做选中态与价格，这两个色在 `Theme.brand` / `Theme.price`，
视图里不写字面值。

### 4.5 阴影

只有三档，**浅色分组列表默认不用阴影**：

| token | 值 | 用在哪 |
|---|---|---|
| `none` | 无 | 分组列表、行、卡片（默认） |
| `soft` | opacity 0.06 / radius 6 / y 2 | 浮层、小组件、看板 |
| `lifted` | opacity 0.12 / radius 16 / y 8 | 拖拽中的图标、模态 |

当前 `WhiteCard` 给每张行卡都加 `radius 8 / y 3`，在 `#F2F2F7` 底上叠出一圈灰边，这是「脏」最直接的一处。

### 4.6 玻璃

| token | 用在哪 |
|---|---|
| `glassRegular` | 容器、按钮、工具栏；iOS 26 走 `glassEffect(.regular, in:)`，低版本退 `.ultraThinMaterial` |
| `glassGlyph` | 只在锁屏数字：字形遮罩内可见，边缘折射高光 |

## 5. 组件库（唯一入口）

| 组件 | 替代什么 | 关键参数 |
|---|---|---|
| `AppScreen` | 现在的 `NavigationStack + header + 完成` | `surface`、导航标题、返回、右上角操作；不再有自造页头和药丸「完成」 |
| `GroupedSection` | 每张独立 `.whiteCard()` | 分组标题、行数组、脚注；整宽、10pt 圆角、行内分隔线、无阴影 |
| `ListRow` | `ScenePage.row(...)` | 左图标（彩色圆角 29×29）、主标题、副文、右侧 value / chevron / toggle / stepper |
| `EventRow` | 日历里的通用 row | 色点 + 起止时间 + 标题 + 地点，全天事件单独一行 |
| `CalendarGrid` | — | 周 / 月视图日期格，今天高亮、有事件的日期带点 |
| `AppToolbar` | — | 底部工具栏（今天 / 日历 / 收件箱 一类） |
| `WidgetContainer` | — | 小组件统一容器，尺寸 2×2 / 2×4 / 4×4 |
| `GlassGlyph` | 锁屏数字 | 字形玻璃遮罩 |
| `CharacterBoardView` | — | 分层立绘 + 点击热区 |
| `ChatMessageMenu` | — | 气泡长按菜单：复制 / 引用 / 编辑 / 撤回 / 删除，两侧共用 |
| `ChatContextBar` | — | 输入栏上方的引用条、编辑条 |

**禁止**：

- 页面里直接写 `.shadow(`、`Color(red:green:blue:)`、`cornerRadius(16)` 这类字面量
- `.whiteCard()` 包整段列表（保留给少量浮层，默认 `shadow = .none`）
- emoji 当图标（健康页的心形换成 SF Symbol 或系统彩色图标）
- 「居中大标题 + 灰色副标题」的自造页头
- 右上角药丸「完成」当唯一出口；系统 App 用返回或左上角关闭
- 每页都套同一个 `row(...)`，由 §6 的结构判据挡住

## 6. 每个 App 的结构判据

验收时逐条对，不做满不算做完。

| App | 必须有 | 不能出现 |
|---|---|---|
| 日历 | 我的 / 发现两个页签；我的＝月份标题 + 周条 + 连通时间线（左侧时间、中间竖线、右侧事件块）；发现＝今天聊过的角色列表，点进去才是他的那天 | 6 张独立白卡列日程、时间线断开、给没聊过的角色预生成日程 |
| 设置 | 整宽分组列表、行内分隔线、脚注贴分组下方、彩色圆角小图标、二级页 push + 返回 | 每组一张带阴影的独立大卡、分组标题飘在卡外 |
| 备忘录 | **我自己的**笔记：搜索框、置顶分组、标题 + 日期 + 摘要的行、右上角新建、点进去可编辑。角色的记忆不在这里 | 用角色当文件夹、把角色记忆当备忘录、行里只有一行字 |
| 通话记录 | 全部 / 未接分段控件、行内类型与时间、右侧 ⓘ | 通用 row 列表 |
| 健康 | 摘要页 + 分类磁贴、顶部日期 | 两张白卡加大片空白 |
| 音乐 | 资料库分组列表 + 底部正在播放条、右上角导入 | 只有导入按钮和空态说明 |
| 角色主页 | 封面 + 压在沿上的头像、名字、签名、标签胶囊、相处天数 / 说话次数 / 记得几件事、下面是他发过的动态 | 纯资料卡、没有签名和标签、把聊天记录当主页 |
| 角色详情 | 身份卡 + 「TA 的（主页 / 日程 / 记忆）」「边界（能不能看我日历）」「设定」「这个会话」四组 | 右上角一个确认框塞完所有操作 |
| 角色记忆 | 只读：他心里的你、记得的事、没说出口的、这几天的日子 | 让用户手填记忆、只有「做过的事」没有日程 |
| 市集（西瓜皮内） | 搜索条、分类胶囊、双列商品流（矢量图标缩略图 / 标题两行 / 价格 / 推荐语 / 来源）、顶部一排「逛逛 / 购物车 / 订单 / 我的」小分段；右上角刷新按当前 tab 决定刷帖子还是刷商品 | 独立占一个桌面图标、两套底栏叠着、订单式列表当首页、假的下单流程 |
| 西瓜皮 | 底部五格（首页 / 市集 / ＋ / 消息 / 我的），发布只走正中间那个 ＋。首页＝搜索条、发现 / 关注页签、双列瀑布流；市集＝分类胶囊 + 双列商品流 + 顶部一排小分段，不再有第二层底栏；消息＝「私信」「分享」两段，两条独立通道各自进各自的对话页；对话层有头像、时间分隔、表情面板、快捷短语与＋号菜单；「我的」＝代码绘制的整幅背景图铺满上半屏 + 压沿头像 + 签名 + 笔记 / 获赞 / 关注 + 九宫格。封面是十二种版式之一：海报、便签、清单、编号、引号、竖排、票根、照片质感、气泡、荧光笔、上下分栏、小票；版式按 seed 稳定选一种，底色另取一个 seed 现算低饱和浅色、与版式不绑定，带 emoji、话题块与正文摘要。笔记详情的作者行有「主页」，进去可以发私信；正文下有「分享到私聊」，选完人帖子以小卡片落进那段对话；角色转给我的帖子也用同一种卡片 | 深色帖子流、纯文字列表、只有一种封面的瀑布流、发布按钮放在导航栏右上角、我的主页没有入口、私信和转帖混成一条消息流 |
| 信件 | 一行一封：发信人、未读点、标题、一行摘要、时间；顶部分段（全部 / 未读 / 收藏）；行尾星标收藏；点进去是米色纸上的衬线正文，右上角也能收藏。信由角色详情页「让 TA 写封信」产生 | 把聊天记录当信、没有发信人、空着也不给入口说明 |
| 通知横幅 | 玻璃卡、左侧 30×30 App 图标、标题 + 一行正文、右上角「现在」、距顶 62pt、4 秒自动收起 | 系统样式的 alert、纯色条、从底部弹出 |
| 信息 / 动态 | 深色玻璃、气泡、输入条；会话列表底部四格「消息 / 通话 / 联系人 / 我的」+ 顶部大标题与搜索、右上角新建；「我的」能改名字、签名、头像；新建角色是白底微信式顶栏，导入区不再是深绿玻璃；通话格能直接发起语音 / 视频、打开通话记录；输入框左侧加号与右上角电话图标也通向语音 / 视频 / 通话记录，语音与视频是文字模拟的通话界面 | 白色分组列表、功能只藏在长按菜单、桌面再放一个电话图标、假装能真的转接系统通话 |
| 默认素材 | 浅色云朵壁纸随包（另三套浅色代码壁纸兜底）；商品缩略图用系统 SF Symbols 按标题匹配、未命中按 seed 随机；路人头像内置 16 款矢量符号按名字哈希稳定分配；首次启动内置「小助手」角色与一批常见指令对话记忆 | 下载第三方图标库、给每个头像打包网图、拿标题首字当商品图 |
| 我的人设 | 设置里二级页：身份列表（首字头像、默认标记、签名或介绍）、新建、编辑（名字 / 签名 / 标签 / 介绍 / 设为默认 / 删除）；角色详情里「我以谁的身份」给单个会话换身份 | 全局一刀切换身份、把身份和角色记忆混在一起、改身份时清空聊天 |

**桌面上只放点开有东西的 App。** 一屏九个：信息、西瓜皮、音乐、日历、备忘录、健康、照片、信件、设置。Dock 四格：信息 / 西瓜皮 / 信件 / 设置。购物已并入西瓜皮的「市集」，不再单独占格。
没有占位图标——点开弹一句「还没做」和没有这个图标，对用户来说是一回事。
电话、FaceTime、计算器、Safari、相机、时钟、天气、提醒事项、地图、钱包、文件、快捷指令、翻译、语音备忘录都已删掉；
通话进了聊天，计算器没有任何场景。

## 7. 深浅与外壳

外壳（锁屏、桌面、聊天、动态）继续锁深色，App 层保留 `.preferredColorScheme(.dark)`。原本打算去掉全局深色、让每个页面自己声明，试算过代价：聊天页、动态页、消息气泡全都会跟着翻成黑字，改动面比收益大得多。

实际做法：

- **角色主页和记忆页属于「外壳」上的页，不是 App**。它们只通过聊天右上角进入，
  所以用 `AppPage`（不自己包导航栈）和浅色 `AppSurface`。
- 浅色 App 声明 `AppSurface.light`，底色、主文字、次文字、分隔线全部取 `AppSurface` 给的绝对色值，不依赖配色方案翻转。
- **整页声明配色方案**。`AppScreen` / `AppPage` 会按 `surface.colorScheme` 给内容挂一次 `environment(\.colorScheme, …)`。系统控件（`Toggle` 的标签、`Picker` 的选项、`TextField` 的占位、`Speech` 的强调色）都从环境里取配色，光靠 `foregroundStyle` 补是补不完的——补漏一个就又是一处白底白字，健康页那条开关就是这么来的。整页挂一次，控件自然按浅色画。
- 自己写的文字仍要显式给色（`Theme.label` / `surface.label`），因为那句 `environment` 只影响系统控件的内部样式，不会替我们改 `Text` 的颜色意图。
- 锁屏和桌面跟随壁纸，不受 App 内页影响。四套壁纸全改浅色：默认用随包的云朵图，其余三套代码绘制；只在顶部压一小段暗角保证白色状态栏可读，不再叠四周暗角。
- 语义色一律用绝对色值（`Theme` 已经这么做）。

## 9. 会自动刷新的页面

购物和小红书的内容不是内置模板，是模型按最近聊天推出来的。规则集中在
`RefreshEngine`，页面只管渲染。

| 项 | 规则 |
|---|---|
| 计数 | 每个页面各自记「距上次刷新过了几轮」，存在 `WorldState.refreshTurns` |
| 判定 | 攒满设置里的间隔（默认 6 轮）之后，按各页面自己的概率掷骰子，默认 20%，可调 2%–60% |
| 按次计费 | 判定通过的页面可以同时刷，内容跟聊天回复在同一个请求里返回 |
| 按量计费 | 同样判定，但一轮最多放一个页面进来，压住多出来的 token |
| 写坏兜底 | 状态块解析失败只丢增量，正文照常上屏；一块里坏掉一条不牵连同批其他条 |
| 提示 | 写入成功后挂一条 `pendingNotices`，外壳弹玻璃横幅；App 不在前台时改发本地通知 |
| 手动刷新 | 右上角一个刷新图标，按当前 tab 走 `.feed` 或 `.shop`：一次独立请求、一次八条，走 `RefreshService`，和自动那条路写进同一份世界状态。入口只在页面上，桌面不放 |

内容生成的约束写在同一处：商品必须有 `reason`（从哪句话推出来的），
笔记必须和最近聊到的事有关。没有线索时允许整轮什么都不刷——
宁可空着，也不要硬凑一批和对话无关的东西。

## 10. 分工

`STANDARDS.md` 管代码与工程：分层、复用表、数据迁移、构建、提交。`DESIGN.md` 管视觉与交互：token、组件库、App 结构、验收判据。改组件时两处都要看：那边决定用哪个既有能力，这边决定它长什么样。
