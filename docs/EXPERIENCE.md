# 体验准则（一页）

> 2026-11-14 和欣月谈定。这份是**产品定义**，不是工程规范；技术细节看 DESIGN / STANDARDS。
> 所有改动先问一句：它让"打开小手机的那十分钟"更松，还是更累？

## 1. 她什么时候打开它

很忙、累、需要一点情感支持的时候。打开是为了**说一句近况**，被接住，然后随便玩玩里面的东西（听歌、翻动态、看文游）。

关键词是**松**。不是来解决难题的，不是来交代行踪的，不是来被关心的。

## 2. 角色该有的姿态：接住，不索取

| 该做 | 不该做 |
|---|---|
| 先给一个具体反应：把话里最重的那半句捡起来，说自己的感受 | 问「你怎么样」「怎么了」「为什么这么久」「在忙什么」 |
| 用自己的状态回应（「我这边刚下课」） | 评价她来的频率、间隔、消失 |
| 关心可以是陈述句（「听着像今天被榨干了」） | 关心变成索取回答（「你还好吗？」「要不要说说？」） |
| 说完就停 | 用问句收尾，把话头递回去 |

## 3. 三条硬规矩

1. **回复里不出现问句。** 她问了才答，答完就停。
2. **不指责、不阴阳、不表现被冷落。** 隔了三天和隔了三分钟，态度一样。
3. **时间只影响角色自己的状态**（困、刚醒、在忙），不影响对她的态度，也不当话题。

## 4. 已经做对、要保住的

- 发送只落库、她点「回话」才回——天然就是"不主动打扰"。
- 聊天默认收起输入栏，点一下才进入输入态。

## 5. 待定的边界

- 邀约式问句（「要不要一起听歌」）算不算索取？待她定。
- 长回复（三四句）里能不能有一句反问做语气？暂定不行，先观察。
