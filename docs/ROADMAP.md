# 功能路线：对照已开源的小手机

这份文档回答一件事：**别人做的小手机里有什么，我们这台能做到哪些。**

写它的起因是已经有人把整套东西开源了，功能清单白纸黑字摆着，没必要再靠猜。但抄功能不等于抄实现——下面每个"可做"都标了在我们这套架构里的落点，不是照着别人的界面复刻一遍。

---

## 1. 看了哪些项目

| 项目 | 形态 | 为什么值得看 |
|---|---|---|
| **Whale 小手机**（`whale-Yd00/freeapp`） | Web + Capacitor 打包 Android | 功能铺得最全，且长期在真实用户手里迭代。聊天、语音、电话、群聊、朋友圈、论坛、一起听歌都有 |
| **FoundPhone Studio**（`keoyyo85/FoundPhone-Studio`） | Web，纯前端 | 思路不同：不做实时对话，做"AI 填剧情数据的互动小说"。49 个 App 页面现成，靠剧情驱动 |
| **ai-virtual-phone**（`binyangzhu000-sudo`） | Next.js | 功能最激进（AI 生图、Supabase 个人云、调用手机快捷指令）。**作者在 README 里明确写了不接受 AI 借鉴挪用**，这里只把它当"能力边界参考"，实现一律不取 |

后两个都是网页套壳，Whale 用 Capacitor 打 Android。**没有一个是原生 iOS**。我们的位置没变：原生 SwiftUI + 液态玻璃，这是网页套壳做不到的部分。

---

## 2. 他们已经做了的，逐项对我们的判断

分四档：**已有**（代码里已经在跑）、**可做**（架构支持，代价可控）、**难做**（要么要钱、要么要服务端、要么要真推送）、**不做**（和"一个人、本地存、零运营"冲突）。

### 2.1 通讯

| 功能 | 他们 | 我们 | 说明 |
|---|---|---|---|
| 单聊 + 流式回复 | ✓ | **已有** | `ChatViewModel` 走 SSE，逐字上屏 |
| 群聊（多角色一个会话） | ✓ | **已有** | 一个 `Companion` 带 `isGroup`，模型按「名字：」分行输出，`ReplyParser.parseGroup` 拆成多气泡 |
| 撤回 / 编辑消息 | ✓ | **可做** | 数据层是 `StoredMessage`，加 `isRecalled` 字段即可；编辑走 `text` 覆写。**约半天** |
| 语音消息（发 / 收） | ✓（接 ASR/TTS） | **难做** | 需要离线 TTS/ASR。Kokoro-82M 量化后约 86MB，见 PLAN.md §4。**这是 P6 的内容，不是顺手能加的** |
| 模拟通话 | ✓ | **可做** | 全屏通话界面 + 系统离线识别 + TTS 朗读 + 插入停顿。观感接近真通话，不花流量钱 |
| 红包 / 转账卡片 | ✓ | **可做** | 纯 UI 卡片，不涉及支付。写个 `CardBubble`，模型输出识别特定标记就渲染。**低成本、高拟真收益** |
| 消息置顶 | ✓ | **可做** | `Companion` 加 `isPinned`，列表排序多一个 key。**一小时** |
| 未读红点 | ✓ | **不做** | 我们的设定是"没有别人给你发消息"，红点会破坏这个前提。桌面图标角标同理 |

### 2.2 角色与记忆

| 功能 | 他们 | 我们 | 说明 |
|---|---|---|---|
| 角色卡导入（酒馆 V2） | 部分 | **已有** | `CharacterCardImporter` 支持 PNG 的 `tEXt` / `iTXt`（`chara` / `ccv3`）和 JSON，V1/V2 都认 |
| 世界书 / 设定集 | ✓ | **已有** | `WorldEntry` + 关键词命中注入。比酒馆少递归触发和插入位置，九成场景够用 |
| 长期记忆 | ✓（含向量） | **已有** | 会话级滚动摘要 + `memoryCursor`；跨会话事实按人名归档进 `WorldState`，单聊群聊读同一份。不做向量检索：单人自用，摘要可读、出问题能直接看到「它以为记住了什么」 |
| 作息 / 生物钟 | ✓ | **已有** | `CharacterClock`，睡眠区间进提示词，深夜回话变短带困意 |
| 多角色互动 | ✓ | **已有** | 群聊已覆盖；跨会话的"角色之间互相知道"没做，**可做**但要另设计数据流 |

## 3. 按代价排的"值得做"

只列我判断**投入产出比成立**的，按从小到大：

| 顺序 | 功能 | 代价 | 为什么要它 |
|---|---|---|---|
| 1 | 消息置顶 | 1 小时 | 每天都要用到的列表操作 |
| 2 | 撤回 / 编辑 | 半天 | 说错话想改是真实需求 |
| 3 | 锁屏密码 + 隐藏模式 | 半天 | 这 App 的界面一眼就是"聊天软件"，被人看到会尴尬 |
| 4 | 红包 / 转账卡片 | 半天 | 纯 UI，但对话的"生活感"立刻厚一层 |
| 5 | 通知中心 / 控制中心 | 1-2 天 | 下拉那一下是拟真的关键动作，现在点了没反应会露馅 |
| 6 | 变量表 + 状态面板 | 2-3 天 | 让角色有"当前状态"，剧情模式才有推进感 |
| 7 | 直播体真界面 | 2-3 天 | 玩法包已经写好提示词了，界面不做等于只做了一半 |
| 8 | 表情包 | 2 天 | 需要配合导出，否则重装就丢 |
| 9 | API Key 轮换 | 半天 | 一个 Key 限流时不用手动改 |
| 10 | 语音 + 模拟通话 | 1 周+ | 体积 +110MB，且要说清"离线中文 TTS 的上限就是清楚不难听" |

## 4. 他们做了我们不该做的

- **注册登录**。所有开源项目都要一个账号才能进，我们不需要。
- **云端存储**。聊天记录留在设备里，比留在任何服务器上都安全，也不需要维护。
- **默认主动推送**。会打断人，且免费签名本来就没有真推送。
- **任意脚本扩展**。酒馆复杂度的根源，也是它劝退你的地方。
- **Android**。多一个平台等于多一倍验证成本，而你没有安卓机。

## 5. 现状对照（2026-11-05）

P0–P5 范围内的代码（39 个 Swift 文件、4515 行）已在 Xcode 26.6 / iOS 26.5 SDK 下全部编译通过，`build.log` 无 error。同一次构建产出 583,178 字节的未签名 ipa 和 5 张模拟器截图（lock / home / chat / moments / settings），逐张核对过：锁屏、24 图标桌面、会话列表空态、动态空态、设置页都完整，没有遮挡或错位。

首轮全绿构建的 5 张截图曾被系统通知授权框盖住，原因是启动即申请通知权限。权限申请已挪到设置开关和第一条回复投递前，`check_standards.py` 会拦截启动路径里的同类调用。过程记在 STANDARDS.md §6 / §8。

**还没验证的**：编译和模拟器截图都是空数据状态下的渲染，不等于功能跑通。聊天持久化、角色卡导入、记忆摘要、备份恢复、流式回复这些都要在装了 API Key 的真机上走一遍。免费签名重装会清沙盒，导出/恢复尤其要实测。

**没做的**：语音（P6）、变量表、直播体界面、消息编辑、锁屏密码。

按第 3 节的排序，语音不在前面——它是体积和体验的天花板问题，其他都是小改动。先把小的做齐，App 的完整度提升比先做语音明显。

### 第二轮（同日下午）

49 个 Swift 文件、`build.log` 无 error，ipa 830,923 字节。§6 的 01–17 里，01/03–15/17 已落地，02 以「人物级事实归档」的形式实现（没有拆 SwiftData 表），16 判定不做。

模拟器截图流水线连踩三次坑，都已修进 `build.yml` 和 `fetch_artifacts.py`：开机未完成就被短超时打断、写到死名单导致新页面拉不回来并混入旧图、app 没退干净造成热启动使 `-previewState` 失效。**目前逐张确认过的**：白色玻璃场景页（健康、音乐）无黑框无遮挡，锁屏的渐变玻璃数字时钟与系统时间同步。其余页面仍以真机为准。

### 「能不能查我自己的手机」核查结果

| 数据 | 结论 | 依据 |
|---|---|---|
| 电量、系统版本、机型、时区、可用空间 | 能 | `UIDevice` / `FileManager`，不需要 entitlement |
| 在这台小手机里开了哪些页面、各待多久 | 能 | App 自己记的 `AppUsageRecord`，本来就落在沙盒里 |
| 步数、心率、睡眠 | 不能 | HealthKit 是受限 entitlement，Personal Team 无法 provision；绕过办法要用 Xcode 连真机跑一次注册 App ID，本机没有 Mac |
| 其他 App 的屏幕使用时间 | 不能 | FamilyControls / DeviceActivity 要 Apple 单独审批 distribution entitlement，只有组织账号持有人能申请，审核按周计 |

所以「查手机」查的是这台小手机里的世界：真机数据只取不需授权的那几项，其余是共同生活里产生的数据。开关默认关，关掉时这整块不进提示词。
