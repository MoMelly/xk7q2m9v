小手机 · 设计稿 v2

这一版只解决一件事：材质。上一版的卡片是实白板，压在那张粉色壁纸上是浮着的、发白的， 所以看起来朴素。这一版全部换成磨砂 —— 壁纸的颜色透上来，边缘只留一圈细高光，阴影几乎没有。
下面六屏是这一批要落地的东西，屏下的编号对应 docs/REQUIREMENTS.md。

材质
三档磨砂，只按用途分

微糊（列表行，4px）／中糊（卡片、小组件，14px）／重糊（Dock、输入条、浮层，22px）。不再有实白底板。

厚度
光在上，压在下的感觉

0.8px 白描边 + 顶部一道更亮的边。阴影半径小、偏移小，只是让边缘离地，不是投影。

对比
谁在说话靠明度分

角色是黑 26% 压进玻璃（沉），自己是白 14%（透）。同一档玻璃，两种底座。

这一版之后排的顺序

  • 本批（已提交）：磨砂材质全套、气泡深浅、消息长按（复制 / 引用 / 编辑 / 撤回 / 删除）、拍一拍、信件分类收藏、TXT 导入阅读。
  • 第二批：主屏小组件（天气 / 火花 / 日程）、今日日程点开详情、情侣空间火花。
  • 第三批：查手机重做（拟真界面 + 世界状态进提示词）、角色心声按钮。
  • 待你定形态：论坛（现在只有西瓜皮提问箱，不是论坛）、世界书常驻面板、公共记忆库。
